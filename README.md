### Featured Systems & Core Projects

#### [Custom_Os](https://github.com/localopensource/Custom_Os)
*Low-level operating system kernel development project.*
- Builds a custom kernel from scratch utilizing the GRUB bootloader, featuring an explicit Makefile pipeline for compiling loaders, kernels, and generating bootable ISO images.
- Explores bare-metal hardware interaction and low-level memory management.

#### [NetLens](https://github.com/localopensource/NetLens)
*High-performance network packet analyzer.*
- Hooks directly into network interfaces via `libpcap` to capture live data-link layer traffic in real time.
- Implements custom Berkeley Packet Filter expressions, decodes IPv4 and TCP/UDP transport headers, and streams structured JSON log exports.

#### [nanoGPT-Study.cpp](https://github.com/localopensource/nanoGPT-Study.cpp)
*Educational C++17 implementation of transformer architectures from scratch.*
- Translates core deep learning Python pipelines into pure C++17 to study backend transformer mechanics without high-level framework abstractions.
- Features a native dataset downloader using `libcurl` and character-level tokenization.

#### [WebSearchEngine](https://github.com/localopensource/web-search-engine)
*Zero-dependency HTTP search engine server.*
- Built entirely on C++11 and POSIX sockets without external web frameworks.
- Implements an in-memory inverted index using whitespace tokenization for constant-time lookups and raw socket HTTP request handling.

#### [LaneVision-LLM](https://github.com/localopensource/LaneVision-LLM)
*Hybrid computer vision and AI driving assistance pipeline.*
- Combines classical computer vision techniques (OpenCV, Canny Edge Detection, Hough Transforms) for real-time lane line extraction.
- Connects local Ollama LLM instances via `libcurl` to translate raw visual road states into natural language summaries.
